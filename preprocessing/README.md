# EMG Preprocessing

This folder contains preprocessing code used for EMG signal understanding.
visualisation, and envelope extraction.

## Code Sources

- **Backyard Brains – Spike Recorder**
  Used for EMG signal visualisation and exploratory analysis.

- **Upside Down Labs – EMG Envelope**
  Used for EMG signal acquisition and EMG envelope extraction.

The code was adapted and integrated for this project.
