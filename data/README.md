# EMG Data Description

This folder documents the EMG data collected and used for this project.
Only representative or sample data is included in the repository.

## Data Type
- Surface EMG (sEMG) signals
- Single channel
- Acquired using Muscle BioAmp Patchy, wearable Electromyography (EMG) sensor that attaches to gel electrodes

## Participants
- Number of subjects: 100
- Data collected for academic and experimental purposes

## Recording Duration
- Duration per trial: Each Movement for 6 sec
- Total recording time per subject: 5 minutes (Average)

## Movements / Classes
EMG data were recorded for the following movements:
- Rest: No movement, representing a neutral position.
- Wrist Flexion: Bending of the wrist.
- Fist Clenching: Closing the hand into a fist.

Total number of classes: 3

## Sampling Details
- Sampling rate: 500 Hz

## Notes
The complete dataset is not included in this repository.
Sample data is provided to illustrate the processing pipeline and data format.
