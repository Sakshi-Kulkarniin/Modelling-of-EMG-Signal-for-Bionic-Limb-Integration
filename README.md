# EMG Signal Acquisition & Processing for Bionic Limb Control

This repository contains the work done as part of my project  
**“Integration of EMG Signal for Bionic Limb Integration.”**

## Overview
The project focuses on real-time EMG signal acquisition, preprocessing, and
machine learning–based interpretation of muscle activity for control
applications.

## Key Work
- Real-time EMG signal acquisition
- Signal conditioning and noise filtering
- Feature extraction from EMG signals
- Machine learning model implementation for EMG pattern recognition
- Analysis of reliability challenges in physiological signal capture

## Tools & Techniques
- EMG sensors and data acquisition setup
- Digital signal processing (filtering, smoothing, normalisation)
- Feature extraction techniques (time-domain features)
- Machine learning models for classification
- MATLAB

## Outcome
The project demonstrates how raw EMG signals can be processed and mapped
to meaningful control signals for assistive or bionic applications.

## Notes
This repository focuses on signal processing and ML logic.
Hardware-specific details are abstracted where necessary.
